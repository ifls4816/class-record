# 🌸 课时记录小程序

一款专为课时管理设计的微信小程序，采用柔和的粉色系配色，界面清新，操作简便。

## ✨ 功能特性

### 📅 首页
- 日历视图查看每日课程，有记录的日期显示圆点标记
  - 粉色点：正常课时
  - 灰色点：未来课时
  - 两点并排：同一天同时存在正常课时与未来课时
- 快速添加 / 编辑 / 删除课程记录
- 支持标记「未来课时」（灰色展示，不计入统计）
- 未来课时可通过长按菜单一键转换为正常课时
- 课程卡片展示时间、学生姓名，支持长按操作

### 👩‍🎓 学生管理
- 双列卡片布局，展示头像、姓名、添加日期
- 按添加时间倒序排列（最新在前）
- 添加、编辑、删除学生
- 启用 / 禁用学生状态，禁用学生置底显示
- 支持搜索学生姓名
- 长按卡片快速启用 / 禁用，或进入编辑
- 编辑弹窗中展示该学生的累计课时与课节数

### 📊 统计分析
- 月度 / 年度课时统计，点击标题切换维度
- 按「学生名-老师名」格式自动分组，展示每位老师下的学生课时排名
- 点击学生查看详细上课记录
- 自动过滤未来课时，仅统计已完成课程

### ⚙️ 设置
- 数据备份（导出 JSON 到剪贴板）
- 数据恢复（从剪贴板导入，含完整数据结构校验）
- WebDAV 云同步：配置服务器后自动防抖上传，支持手动同步与从云端恢复

## 🎨 设计特色

- **主色调**：粉色系渐变 `#ff7b8a → #ff9aa2`
- **大圆角卡片** + **柔和阴影**，层次清晰
- **交互反馈**：按钮点击缩放、弹窗滑入动画
- **弹窗锁定背景滚动**，防止误操作

## 🚀 快速开始

### 1. 准备图标资源

在 `static/tabbar/` 目录放置以下 TabBar 图标（81×81 px）：

```
home.png            首页图标（灰色）
home-active.png     首页图标（彩色）
student.png         学生图标（灰色）
student-active.png  学生图标（彩色）
chart.png           统计图标（灰色）
chart-active.png    统计图标（彩色）
setting.png         设置图标（灰色）
setting-active.png  设置图标（彩色）
```

在 `static/icon/` 目录放置以下业务图标：

```
time.png    时间图标（首页课程卡片）
people.png  人物图标（首页课程卡片）
search.png  搜索图标（学生列表搜索栏）
```

### 2. 配置小程序 AppID

打开 `manifest.json`，在 `mp-weixin.appid` 中填入你的微信小程序 AppID。

### 3. 运行项目

在 HBuilderX 中：
1. 打开项目
2. 运行 → 运行到小程序模拟器 → 微信开发者工具

## 💾 数据存储

使用 uni-app 本地存储 API 持久化数据：

| Key | 内容 |
|-----|------|
| `class_record_students` | 学生列表 |
| `class_record_class` | 课程记录（按年/月/日嵌套） |

数据结构：
```ts
// 课程记录
interface TodayClass {
  studentId: number | null
  time: [string, string] | []   // [开始时间, 结束时间]
  timeDiff: number              // 时长（分钟）
  isFuture?: boolean            // 是否为未来课时
}

// 学生
interface Student {
  id: number
  name: string          // 格式建议：学生名-老师名
  createTime: string
  disabled: boolean
}
```

## ☁️ WebDAV 云同步

1. 进入「设置」→「WebDAV 配置」
2. 填写服务器地址、用户名、密码（支持坚果云等标准 WebDAV 服务）
3. 可测试连接后保存
4. 数据变更后自动防抖同步（延迟 3 秒）；也可手动「立即同步」或「从云端恢复」

## 📊 数据备份与恢复

**备份**：设置 → 备份数据 → JSON 数据复制到剪贴板 → 粘贴保存

**恢复**：将备份 JSON 复制到剪贴板 → 设置 → 恢复数据 → 确认覆盖

## 🎯 使用指南

### 添加课程记录
1. 首页点击右下角浮动按钮
2. 选择学生、日期、开始/结束时间
3. 可开启「未来课时」开关标记预约课程
4. 确认添加

### 管理学生
1. 进入「学生」页面，点击右下角「+」添加学生
2. 姓名格式建议：`学生名-老师名`（统计页将按老师自动分组）
3. 长按卡片可快速启用/禁用或进入编辑

### 未来课时转正
1. 首页长按未来课时记录
2. 选择「已上课」，即可转换为正常课时并计入统计

### 查看统计
1. 进入「统计」页面
2. 点击顶部时间标题切换月度/年度视图
3. 左右箭头切换时间段
4. 点击学生查看详细上课记录

## 💡 使用提示

1. **首次使用**：先在「学生管理」添加学生，再到首页添加课程记录
2. **学生命名**：使用「学生名-老师名」格式，统计页将自动按老师分组
3. **数据安全**：定期备份，或配置 WebDAV 自动同步
4. **禁用学生**：不再上课的学生可禁用，历史记录不受影响
